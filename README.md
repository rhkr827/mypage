# 곽승우 (Seungwoo Kwahk) - Portfolio & Resume

반도체 오버레이 계측장비 SW 및 데이터 분석 솔루션 7년+ 경력의 소프트웨어 엔지니어 곽승우의 정적 포트폴리오 및 이력서 웹사이트입니다.

---

## 🌐 미리보기 & 실행 방법

의존성 설치(`npm install`) 없이 즉시 확인할 수 있습니다:

### 1. 브라우저에서 바로 열기
`index.html` 파일을 더블 클릭하여 크롬이나 엣지 등 브라우저에서 바로 확인합니다.

### 2. 로컬 웹 서버 실행 (선택)
```bash
# Python 내장 서버
python -m http.server 3000

# 또는 npx serve
npx serve .
```
브라우저에서 `http://localhost:3000` 접속

## ✨ 주요 특징

- **단일 파일 정적 구조 (Zero-Dependency)**: 빌드 과정 없이 `index.html` 단독으로 완벽하게 동작하며, GitHub Pages에 바로 배포 가능
- **현대적 UI/UX**: Tailwind CSS 기반의 반응형 인터페이스, 글래스모피즘 헤더, Pretendard & Inter 폰트
- **다크/라이트 모드 지원**: 사용자 시스템 테마 자동 인식 및 로컬스토리지 상태 저장
- **PDF 이력서 인쇄 최적화 (`@media print`)**: `PDF / 인쇄` 버튼 클릭 시 웹 전용 요소가 숨겨지고 깔끔한 A4 포맷 이력서로 출력
- **상세 도메인 & 경력 정리**:
  - (주)오로스테크놀로지 (Overlay 계측 장비 제어 SW, SECS/GEM, 오버레이 모델링 시뮬레이터, C++ MFC / C# WPF)
  - (주)우원테크놀로지 (독일 Qoniac사 Ovalis 반도체 공정 분석 솔루션 운영, C# 로그 분석기 자체 개발)
  - 핵심 프로젝트 및 언어별 기술 스택 매트릭스
